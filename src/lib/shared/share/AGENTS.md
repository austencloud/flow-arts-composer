# Sharing and export

Before changing sharing, downloading, device transfer, or social publishing, read
`docs/architecture/sharing-export-experience.md` from the repository root. It
preserves Austen's reported failures, the primary-source research, product
decisions, browser limitations, behavior owners, and acceptance checks.

Extend that record when new evidence changes a decision. Do not restart the
foundational research or combine link sharing, file export, and social publishing
into one equally weighted control panel. Preserve entry context, one-click copy,
explicit download intent, cancellation, and honest handoff feedback.

The app name is Flow Arts Composer. TKA refers to the notation system only.
