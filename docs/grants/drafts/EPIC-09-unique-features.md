# Epic MegaGrants: Unique Features

**Portal prompt:** Please tell us about some of the unique features of your project.

**Limit:** 32,000 characters

**Approved by Austen:** August 30, 2026

**Portal text:**

The Kinetic Alphabet does something that sounds obvious because it should already exist. It lets a person read coordinated movement with one handheld prop in each hand from a page, much as a musician reads a score. Its symbols record where each hand travels and how each prop turns. Flow Arts Composer takes the written sequence and makes it move on a 3D performer. In The Kinetic Archive, players will encounter those written movements as performances inside the museum.

A practitioner can read a sequence, watch the same phrase from any angle, slow it down, and compare the notation to the performance. The museum will make that act of looking part of the game. Its fictional bureaucracy treats spinning sticks as an ancient mystery, but the system the player will learn is real.

The alphabet's levels expand a bounded motion space. Each level adds defined choices for the hands and props, then extends the system into new grid locations and spatial planes. A movement does not have to remain an isolated trick someone saw once at a festival. It can be placed beside its relatives. The goal is for someone to discover a pattern and recognize the named movements inside it. The notation then gives them a way to explore nearby possibilities. I think of that as a curiosity-enhancing machine.

The shared language also gives the field a memory. A physical discovery can become a score another performer reads and a 3D example they can examine. A developer could use that movement record in another interactive project instead of reconstructing the technique from a flat video. Techniques that currently live only in individual performers' bodies can survive long enough to be studied, challenged, taught, and extended.
