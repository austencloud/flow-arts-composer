> developers. The project's GitHub repository already includes MIT-licensed
> domain and rendering packages, plus CC-licensed notation and sequence data.

> attributed sample clips. The full cleaned mocap library can remain separately
> licensable, giving developers a useful foundation without starting from
> scratch.
