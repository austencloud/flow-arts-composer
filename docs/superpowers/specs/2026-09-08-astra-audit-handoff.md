Fix the composition: phone candidates are still **52px** (the original issue was roughly 48px), the compact flow is tall, and the preview is too subordinate at some sizes. Increasing picker height did not increase the width-limited candidates. Revisit the existing option-grid sizing/layout owner; avoid another caller-only height adjustment.

Replacement intentionally truncates later beats to preserve validity and says so in the UI. This is not a settled replacement policy for the full editor. Preserve real workspace history/state, option validity, renderer activity/lifetime and the existing full viewer for focused practice/share.

4. **Complete visual acceptance before product promotion:** seven tiers, actual 200% zoom, reduced motion, first load/empty/long sequence states, configuration disclosure, build -> audition -> selected-beat edit -> undo -> seek -> play. Retain a single preview renderer through edits; do not introduce dialog round trips. Existing current-module state should remain the authority.
5. **Evaluate the Browse content-first experiment separately.** Current GallerySplitPane defaults to a 440px expanded pane and already supports collapse/resize/keyboard/persistence. Specific category entry opens its editor, explicit saved preferences win, and active filters stay visible/removable. No default change or usability benefit was established. Compare known-sequence finding and multi-filter narrowing before adopting it.
6. **Optional confidence work:** inject recoverable shell/retained chunk failures in a suitable dedicated browser; measure actual production transfer/evaluation and Browse interaction timing if needed. Do not rerun broad profiling or refactor further solely because the proxy numbers are large.

## Gotchas

- Read current AGENTS.md and relevant skills on the destination machine; do not hard-code this machine's C: paths. The repository's older instructions also mention E:. Create a dedicated main-based worktree for implementation and preserve concurrent work.
- Do not start/restart/kill Austen's port 5173 dev server. Use its configured IPv6 HTTPS endpoint or a task-owned free port under the resource budget. Stop task servers in the same turn. At most two agent Vite servers and one svelte-check; check available memory before heavy processes.
- The main branch advanced several times during this audit. Primary prop colors, collection props, prop viewing, analytics and desktop infrastructure landed independently. Use merge ancestry and scoped diffs to distinguish them from this batch; do not revert those changes.
- SvelteKit route regeneration and new Vite dependency optimization caused repeated reloads, stale dynamic-import hashes, and even a transient wrong test page at the same URL during checks. Reload the correct fixture after the server settles; do not misdiagnose a transient HMR state as final product behavior. No production timing conclusions were drawn from these cold development loads.
- Reset `+layout@.svelte` bypasses the parent `/test/+layout.ts` guard. The prototype therefore has its **own** dev redirect in its local `+layout.ts`; preserve it.
- A disposed AnimationEngine cannot be reused on retry. The fix creates a new engine and activity gate. Keep async disposal/registry guards intact, including newer primary-color propagation.
- A shared Browse load revision must not invalidate an in-progress public/community request on every account change without reloading it. The follow-up puts that invalidation inside the Library-specific branch. Preserve the regression test.
- Failed retained module IDs need the `!moduleErrors.has(id)` guard as well as the cache guard; otherwise navigating elsewhere starts invisible retries and clears errors.
- A direct jsdom ModuleRenderer failure harness was attempted and removed: Svelte template cloning failed before assertions and the mocks pulled in a large unrelated graph. No passing failure-injection test was claimed. Prefer a bounded real-browser interception approach rather than restoring source-string tests or an oversized mock world.
- The earliest standalone HTML sketch was illustrative, and its file URL was blocked by browser security. It is not included or needed. The actual app fixture is the artifact to inspect; do not try to serve that old sketch to bypass the block.
- Screenshots/measurements in this handoff are historical evidence. Reproduce on the desktop before claiming new UI acceptance. No expert-owned canon was changed by this work.
