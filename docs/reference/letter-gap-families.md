# Letter Gap Families — the one-hand rotation structure

**Established 2026-08-05** (Austen + Fable session, sequence-combinator redesign).
Derived by exhaustive computation over `DiamondPictographDataframe.csv` +
`BoxPictographDataframe.csv`: 100% coverage, zero unmapped letters.

## The operation

Hold one hand's motions fixed. Rotate the **other** hand's locations by a
multiple of 90°. Every resulting motion tuple is a legal pictograph, and it
carries a different letter.

Nothing about the dance changes — each hand keeps its own path, motion type
(pro/anti), and rotation direction. The only thing that changes is the **gap**
between the hands, and therefore the placement family that describes it:

| Gap between hands | Placement family | VTG timing |
|---|---|---|
| 0° (same point) | beta | Together |
| 90° (right angle) | gamma | Quarter |
| 180° (opposite) | alpha | Split |
| 45° / 135° | zeta, eta | (skewed) |

**A letter is not an atom. A letter is (motion character, gap).**

## The 13 families

Members of a family are the same motion character seen at different gaps.
Verified 2026-08-05 as undirected connected components under 90/180/270
one-hand rotation.

| # | Family | Character |
|---|---|---|
| 1 | A, G, S | Type 1, same direction, both pro |
| 2 | B, H, T | Type 1, same direction, both anti |
| 3 | C, I, U, V | Type 1, same direction, hybrid |
| 4 | D, J, M, P | Type 1, opposite direction, both pro |
| 5 | E, K, N, Q | Type 1, opposite direction, both anti |
| 6 | F, L, O, R | Type 1, opposite direction, hybrid |
| 7 | W, Y, Σ, Θ | Type 2, shifting hand pro |
| 8 | X, Z, Δ, Ω | Type 2, shifting hand anti |
| 9 | Φ, Ψ, Λ | dash pair + its gamma form |
| 10 | W-, Y-, Σ-, Θ- | Type 3, shifting hand pro |
| 11 | X-, Z-, Δ-, Ω- | Type 3, shifting hand anti |
| 12 | Φ-, Ψ-, Λ- | dashed dash family |
| 13 | α, β, γ | static holds |

**TKA already named this.** The family is the VTG *direction* class plus spin
character; the member within it is the VTG *timing* class. Split-Same (A),
Together-Same (G) and Quarter-Same (S) were never three unrelated letters —
they are one motion at three separations, and the existing names say so.

## The 180° map (a total involution)

A↔G · B↔H · C↔I · D↔J · E↔K · F↔L · M↔P · N↔Q · O↔R · U↔V · W↔Y · X↔Z ·
Σ↔Θ · Δ↔Ω · Φ↔Ψ · α↔β

Self-paired: **S, T, Λ, γ, Λ-**.

This is NOT the pro/anti twin involution (A↔B, G↔H, S↔T — see
`reference_twin_letter_involution`). Two different involutions act on the
letter set; do not conflate them.

## Why S is its own partner

Gamma has 16 variations where alpha and beta have 8. In the same-direction
families, one letter covers *both* right-angle arrangements — S has 32 dataframe
rows where A and G have 16 each — so rotating one hand 180° maps S onto itself.
In the opposite-direction families the two right angles are split across two
letters (M/P, N/Q, O/R), 16 rows each, so they map onto each other instead.

That is exactly why Quarter-Same has 4 letters (S, T, U, V) and Quarter-Opposite
has 6 (M–R).

## The group behind it (added 2026-08-05)

The families above are orbits, which means there is a group. It was computed
directly: `scripts/combinator-research/letter-group.mjs` treats each structural
transform as a permutation of the **1152 distinct pictographs** (576 diamond +
576 box) and generates the group from them.

Working on pictographs rather than letters is what makes this well defined. On
letters the maps are many-valued — A rotated 90° is S, but so is A rotated 270°
— so "the group acting on letters" does not exist. On pictographs every
transform below is a bijection, the group is a real group, and **letters are the
quotient**.

### Which transforms are closed

Measured over all 1152 pictographs:

| Transform | Lands legal | Keeps its letter |
|---|---|---|
| rotate one hand 90° (**the gap step**) | 100% | 0% |
| rotate one hand 180° (**the gap involution**) | 100% | 11% |
| twin, both hands — pro↔anti with rotation flipped | 100% | 28% |
| twin, one hand only | 100% | 33% |
| swap hand colours | 100% | **100%** |
| rotate **both** hands 45° (diamond↔box) | 100% | **100%** |
| rotate one hand 45° (**skew**) | **0%** | — |

Two of these are letter-invariant, which is the formal version of facts already
in the codebase: colour swap never changes a letter, and diamond↔box is a
letter-preserving bijection, not two separate alphabets.

Skew is the outlier: **all 1152 land off the shipped map, not some.** That is a
sharper statement than "the skewed dataframe is incomplete" — the odd gap step
is entirely absent from shipped data.

### The group orders

| Generated by | Order | Letter classes |
|---|---|---|
| gap step alone (90°) | 4 | **13** — the families above, re-derived |
| gap involution × twin involution | 4 (Klein four) | 18 |
| gap step (90°) × twin | **8** | **9** |
| every closed transform | 256 | 7 |

The handoff's open question was what the gap and twin involutions generate
together. They **commute**, giving the Klein four-group of order 4 — so A relates
to H by a single composite element, and `{A, B, G, H}` is one class. Nothing
deeper is hiding there.

The more useful object is the **order-8 group** generated by the full 90° gap
step and twin. Its 9 classes are the natural "master boxes":

```
{ A B G H S T }   { C I U V }   { D E J K M N P Q }   { F L O R }
{ W X Y Z Σ Δ Θ Ω }   { Φ Ψ Λ }   { W- X- Y- Z- Σ- Δ- Θ- Ω- }
{ Φ- Ψ- Λ- }   { α β γ }
```

### Characters × gaps — the bijection

The gap step has **288 orbits, every one of size 4**, and each orbit hits each of
the four even gaps **exactly once — 288 of 288, 100%**.

So `letter = (motion character, gap)` is not a slogan. It is a measured
bijection: **288 characters × 4 gaps = 1152 pictographs**, no exceptions, no
leftovers. The 47 letters are what you get when you name those 1152 cells with a
coarser vocabulary.

### Why families are size 3 or 4

Every character produces one of **21 distinct (gap → letter) patterns**:

| gap 0 (beta) | gap 2 (gamma) | gap 4 (alpha) | gap 6 (gamma) | size | character |
|---|---|---|---|---|---|
| G | S | A | S | 3 | both pro, same |
| H | T | B | T | 3 | both anti, same |
| Φ | Λ | Ψ | Λ | 3 | dash + static |
| Ψ- | Λ- | Φ- | Λ- | 3 | dash + dash |
| β | γ | α | γ | 3 | static + static |
| D | M | J | P | 4 | both pro, opp |
| D | P | J | M | 4 | (the other chirality) |
| I | U | C | V | 4 | hybrid, same |
| F | O | L | R | 4 | hybrid, opp |
| Θ | W | Σ | Y | 4 | pro + static (Type 2) |
| Σ- | Y- | Θ- | W- | 4 | dash + pro (Type 3) |

(abridged — the script prints all 21.)

**The law: a family is size 3 exactly when the two gamma slots share one letter
name, and size 4 when they carry different names. Nothing else varies.**

Size-4 characters come in **chirality pairs** — `D M J P` and `D P J M` are both
real patterns, 8 characters each. Size-3 patterns have no partner: swapping their
two gamma slots reproduces the same string.

The direction column above is the dataframe's own VTG `direction` value. **Do not
re-derive it from the two `rotationDirection` fields.** For a hybrid the props
counter-rotate while the hands travel together, so prop-direction agreement is
the *inverse* of hand-direction agreement — deriving it that way labels C/I/U/V
"opposite" and F/L/O/R "same", which is backwards. (This page briefly carried that
error on 2026-08-05; the canonical column is `direction` in the CSV.)

### The mechanism — half solved

Reflection turns out to be **letter-preserving (100%, 16 fixed points)** and
gap-reversing, which makes it the natural candidate. The right question is not
"does reflection link the two gamma slots" but "**is the character its own
reflection?**" — reflection maps a character onto its chirality partner, and a
character that is its own partner cannot tell its two right angles apart.

Measured over all 288 characters:

| | fused (size 3) | split (size 4) |
|---|---|---|
| character is its own reflection | **32** | **0** |
| reflection carries it to a distinct partner | 32 | 224 |

**Self-reflective ⟹ fused, with zero exceptions.** That direction is airtight and
it explains the shift families: A/G/S and B/H/T fuse because their motion
character is its own mirror image.

It does not explain the other 32. Those are the dash and static characters
(Φ/Ψ/Λ, Φ-/Ψ-/Λ-, α/β/γ), which fuse for a second, different reason — plausibly
that a held or dashed hand has no chirality to distinguish in the first place,
but **that has not been verified**. Confirming it is the remaining work.

Ruled out along the way, each covering some fused characters but never wrongly
fusing a split pair: colour swap (0 of 64), reflection about N–S alone (8),
reflection composed with colour swap (0), some reflection linking the slots
directly (32).

## Sequence orbits

A sequence's orbit is every letter walking its own family in lockstep. Verified
on EK+GG (a combination requiring a prop reversal):

| Red rotated | Word | World | Path | Closes |
|---|---|---|---|---|
| 0° | EKGG | diamond α/β | beta3 → alpha5 → beta7 → beta1 → beta3 | yes |
| 90° | NQSS | gamma | gamma5 → gamma15 → gamma1 → gamma3 → gamma5 | yes |
| 180° | KEAA | diamond α/β | alpha7 → beta1 → alpha3 → alpha5 → alpha7 | yes |
| 270° | QNSS | gamma | gamma9 → gamma3 → gamma13 → gamma15 → gamma9 | yes |

E and K sit in family 5, G in family 1; every face is those families re-gapped
together. Reversal structure is invariant across the orbit — rotating locations
never touches spin direction — so all four faces carry the same 3 prop
reversals. Same loop, same flaw, four labels.

**Independent confirmation:** running the same rule on ALGF reproduced two
sequences Austen had hand-built in the constructor before this rule existed —
90° gives SRSO, 180° gives GFAL, both letter-for-letter.

## What a card pair's fingerprint measures (added 2026-08-05)

The handoff recorded fingerprint counts — 256 for A+G, 512 for A+H, 7396 for
A+B — as a table of observations. With the gap coordinate in hand they turn out
to be one rule, and it was tested by prediction rather than curve-fitted.

`scripts/combinator-research/pair-classes.mjs` states a model, derives each
pair's prediction from structure alone, then runs the exhaustive enumeration and
scores itself. The first model — *"a base per gap separation, halved when the
cards share a family"* — predicted 1024 for a different-family gamma pair.
**A+U, A+T and B+S all measured 512. Refuted, in one nameable cell.**

The corrected law:

> **Every cross-world card pair fingerprints 512 words. It halves to 256 exactly
> when the two cards are gap-involution partners — the same motion character at
> opposite gaps (A↔G, B↔H, C↔I). Separation into gamma never halves, whether or
> not the cards share a family.**

So the fingerprint answers one question: *are these two cards the same character
seen at opposite gaps?* 256 means yes, 512 means no. Same-world pairs are a
different regime entirely — no bridge is needed, every interleaving is legal, and
the count explodes (7396 for alpha/beta, 23466 for gamma's doubled slots).

Runnable single-letter cards are only ten — A, B, C (alpha), G, H, I (beta),
S, T, U, V (gamma) — spread across just three families, so the separation-4
partner cell has exactly three members and all three are measured.

**The halving is not "shared family."** C+U and C+V share a family and measure
512; A+U and A+T do not share one and also measure 512. Family membership only
matters when the separation is 4.

### Compound cards — a separate regime, now fully measured

A compound card (DJ, EK, FL, ΦΨ, MP, NQ) spans two gaps by construction, so it
always overlaps its partner's world and never needs a bridge. Those pairs live in
the exploding regime. The `theory-512.mjs` sweep completed 2026-08-05 — including
the four rows the handoff recorded as unfinished:

| Pair | Words | By length |
|---|---|---|
| A+DJ, G+EK, A+FL, A+ΦΨ, G+ΦΨ | **7620** | `3:21 4:326 5:1373 6:4000 7:1600 8:300` |
| DJ+EK, DJ+FL | **10456** | `2:2 3:24 4:340 5:1520 6:5552 7:2472 8:546` |
| S+MP | **78103** | |
| MP+NQ | **214795** | |

Two things worth noticing. **7620 is a five-way tie with byte-identical length
distributions** — a card plus any opposite-direction or dash compound gives the
same answer, whichever card and whichever compound. So does 10456 across DJ+EK
and DJ+FL. That is the family structure again: the alpha and beta versions of one
question have one answer.

And **A+ΦΨ measures exactly what A+DJ measures**, even though a dash crossing
advances the loop 180° where a shift crossing advances it 90°. The fingerprint
cannot see that difference; the count bucket can (it is what separates the
4-count from the 16-count). The two numbers measure different things — do not
expect one to predict the other.

## The 45° case (skew)

Rotating one hand 45° puts it on the diagonals while the other stays cardinal.
Austen built a working closed 4-step skewed loop this way (`G F A L` in eta/zeta
placements), and skew **keeps the original letter names** — the skew generator
applies skew to existing diamond/box pictographs and preserves the letter.

Before 2026-09-21, `SkewedPictographDataframe.csv` (byte-identical in
`static/data/pictographs/` and `mcp-server-pkg/assets/data/pictographs/`, 5120
rows) contained **no rows that start from a skewed placement**. Its start
placements were only alpha/beta/gamma. `scripts/generate-skewed-dataframe.ts`
built it by applying skew to existing diamond and box pictographs, so it
described stepping *into* skew and never continuing *within* it.

Consequence at the time: a closed loop that stays in skew could not be
expressed from the shipped data, even though it was performable. Extending
the generator to cover skew→skew transitions was the unlock for skewed LOOPs.

Described as of 2026-09-21: the skewed alphabet in
`docs/superpowers/specs/2026-09-21-skewed-frame-lettering-design.md` letters
all 1152 skewed-frame beats with 38 letters. The generator writes those rows
to `static/data/pictographs/SkewedPictographDataframe.csv` (6272 rows: 3072
category 1, 2048 category 2, 1152 category 3). The
`mcp-server-pkg/assets/data/pictographs/` copy is a mirror of that file, kept
in sync by copying it over, and now carries the category 3 rows too.

## What this changes

1. **Search orbit representatives, not letters.** 13 families instead of 47
   letters; roughly a 4× reduction in combination search, with gamma and box
   material arriving free rather than as a deferred cross-mode feature.
2. **Dedup at the family level.** Four faces of one loop are one discovery with
   four presentations, not four results.
3. **Do not widen the combinatorial space — factor it.** The generator should
   work on (motion character, gap) rather than on opaque letters. The space gets
   smaller while covering more.

## Reproduce

Everything on this page is computed by `scripts/combinator-research/`
(see that directory's README for limits — diamond-only enumeration, a local
reimplementation of the closure rule, and counts that move with the equivalence
relation).

| Claim | Run |
|---|---|
| the 13 families, the 180° involution | `node scripts/combinator-research/letter-orbits.mjs` |
| the group, 288×4 bijection, family-size law, skew closure | `node scripts/combinator-research/letter-group.mjs` |
| the fingerprint law, predicted then measured | `node scripts/combinator-research/pair-classes.mjs` |
| count buckets and the crossing law | `node scripts/combinator-research/by-count.mjs` |

The lookup key throughout is the full 8-field motion tuple (`blueMotionType,
blueRotationDirection, blueStartLocation, blueEndLocation`, same for red).
Any reimplementation must reproduce the 13 families exactly; if it does not, the
key is wrong.

**Cross-checked against the domain server, 2026-08-05.** `compare_letters("S","A")`
reports 16 variations for S against 8 for A, with the *only* difference being
`gamma→gamma` vs `alpha→alpha` — identical type, motions and rotation directions.
`compare_letters("M","P")` reports 8 each and "no major differences". That is the
family-size law from a completely separate code path: S is one name covering both
gamma slots, M and P split them.

It also exposes a real gap in `compare_letters` — the coordinate that actually
distinguishes M from P is the gap slot, and the tool does not carry it, so it
reports two genuinely different letters as identical.
