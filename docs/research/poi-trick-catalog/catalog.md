# Poi trick name catalog, 2026-10-22

See [README.md](README.md) for what this is and how to read it.

Compiled from public names and titles only; descriptions are my own words. Timing uses VTG codes only where a source states it or the move's definition makes it unambiguous: TS = together/same-time same-direction, TO = together-time opposite-direction, SS = split-time same-direction, SO = split-time opposite-direction. Blank = not stated.

Source shorthand (full URLs in the Sources section):

- `H:<Category>/<slug>` = Home of Poi lesson at `https://www.homeofpoi.com/us/lessons/teach/POI/<Category>/<slug>`. Only the lesson title (slug) was read for most of these, not the lesson body, so descriptions come from the title plus general poi knowledge. Rows whose description is a guess say "(?)".
- `HT` = Home of Poi "Poi terminology" lesson. `WPD` = Wikipedia "Poi definitions". `WB` = Wikibooks "Juggling/Poi tricks". `WP` = Wikipedia "Poi (performance art)".
- `DRX:"title"` = video title on the DrexFactor YouTube channel (@drexfactor). `PP:"title"` = video title from the playpoi YouTube channel (found via YouTube search listing).
- Lvl: B = filed under a Beginners category on Home of Poi; A = filed under an Advanced category; I = title says intermediate; "5L" = a DrexFactor "5 levels" video exists. Blank = no level given.
- In VTG / app: where the trick already exists in this project. **VTG** = the `packages/vtg-domain` data (named patterns, shapes, hybrids). **Shape Engine** = the `/shape-engine` flower grid (pro and anti flowers 0–3 turns, in/out, in six timing/direction modes, 2D only). **App** = elsewhere in the app. "—" = not in the project yet. Matched by name and family rules, then spot-checked; treat it as a lead, not a verdict.
- Plane: wall, wheel, horiz (horizontal), buzz (Home of Poi's "buzzsaw plane"), 3D. Only where a source or the move's definition says so.
