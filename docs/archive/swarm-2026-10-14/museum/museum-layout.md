# TKA Museum - Layout & Flow

> This document describes the physical layout of the museum, room by room.
> Main path items are required. Easter eggs are optional discoveries.

> **REVISION NEEDED** — The numbered wing system (Wing 1-8) is retired. The narrative structure now uses 5 phases (see `story-bible.md` § "The Museum Experience"). Wing 8 (Austen Wing) no longer exists — Austen is one of many Scribes, not a featured Vessel with his own wing. The three-door endings are superseded by sequential rooms. This file is kept for spatial reference only.

## Wing 1: Ancient Origins

**Theme:** Paleolithic discovery, cave paintings, stone tablets
**Lighting:** Dim, torchlight simulation, reverent
**Audio:** Dripping water, distant echoes, silence

### Main Path Items

| Item | Type | Description |
|------|------|-------------|
| Lascaux Tablets | Artifact | Stone tablets showing OOGA and UG sequences |
| Cave Painting Recreation | Mural | Full wall recreation of the "rehearsal chamber" |
| Dr. Marchand Display | Plaque + Photo | The discoverer, his notes, "published posthumously" |
| Prop Recreation | Physical | Three caveman clubs (animated in 3D space, performing UG sequence) |

### Hidden Elements

| Item | Location | Notes |
|------|----------|-------|
| Spiral #1 | Ceiling | Part of the cave painting, easy to miss |
| Spiral #2 | Floor tile | Near the exit to Wing 2 |

## Wing 6: The Suppression

**Theme:** Protocol Lethe, the Order revealed, institutional dread
**Lighting:** Fluorescent flicker, institutional lighting, sterile
**Audio:** Distant hold music, paper shuffling, fax machine hum, oppressive silence

> **CRITICAL:** This is the reveal wing. The Order of the Closed Palm is named here for the first time.

### Main Path Items

| Item | Type | Description |
|------|------|-------------|
| "The Order of the Closed Palm" | Large Display | Full explanation, symbol prominently displayed |
| Protocol Lethe Documentation | Display | Redacted files, global maps, timeline |
| "You've Seen This Before" | Interactive | Shows where the symbol appeared in previous wings |
| May 8, 1994 Display | Plaque | Austen's birth, the head trauma, the immunity |

### Atmosphere

This wing should feel bureaucratically suffocating. The visitor realizes the Order's symbol has been stamped on everything the whole time - not watching them, just ever-present in the way that institutional logos are. The previously subtle hints are now overwhelming.

### Hidden Elements

| Item | Location | Notes |
|------|----------|-------|
| Spiral #9 | Exit doorway | Almost defiant placement - exiting toward hope |
