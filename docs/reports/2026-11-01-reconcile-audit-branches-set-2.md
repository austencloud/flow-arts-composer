## Method

1. The session's own commits are the non-merge commits after the branch base
   `c4be16199` (PR #48 merge, 2026-09-12). The startup branch sits on
   `6e4c1b5a3` (PR #49 merge); its inherited commit `551df2688` is Austen's and
   is excluded. The guest-save branch also carries four `docs(audit)` commits
   from 2026-09-12 that predate its merge of `c4be16199`; they are included.
2. For every touched file the branch tip was diffed against `main` at the
   landing commit (`git diff <branch> <landing> -- <path>`). Where that was
   not byte-identical, the branch tip was diffed against current `origin/main`
   after normalising both sides with the repository's prettier config and the
   `$lib` to `#lib` import codemod, and the residual was read by hand.
3. Evidence: the 34 test files these branches own were run from this branch
   with `npx vitest run --config tests/config/vitest.config.ts`. Results:
   17 files, 90 passed, 9 expected failures (`it.fails` repros) for the
   persistence, thumbnail and startup suites; 17 files, 168 passed for the
   guest-save suites. Logs are not committed.

Classification key: `landed` means `main` has the change, possibly moved,
reformatted or extended. `landed (evolved)` means `main` carries the change
plus later edits that supersede the branch wording.
