# Lab and test-page trim: what to remove, 2026-10-22

Research only. Nothing was deleted or edited in product code. Every number comes from `git log`, `git grep` and line counts run in the `codex/lab-trim-census` worktree on 2026-10-22.

## What this is

- **205** entries under `src/routes/test/`, **17** Lab tabs, **31** feature folders that are not registered as modules, and **6** other experiment routes are in the inventory at the end.
- Every `/test/*` page is dev-only: production empties the component and redirects to the gallery (`src/routes/test/+layout.ts`). Removing them frees repo size, type-check and build time. It changes nothing for users.
- The Lab module is `adminOnly` (`module-definitions.ts:485`), so Lab tabs are reachable only from the admin menu. No `/test/*` page is linked from a menu. "Address only" in the table means no in-app link was found.
- **Last real change** is the newest commit that touched the path and changed 40 files or fewer and is not a sweep. I skipped subjects starting with `Types`, `i18n`, `Prettier`, `lint`, `Format`, `Merge`, `rename(app)`, `fix(types)`-style, `feat: migrate to SvelteKit 3`, `refactor(motion)` and `fix(test-routes)`. That shows through when a date looks older than the page feels (the Oct 10 migration touched every page). Dates can still be off for a page that only ever got bulk edits.
- **Refs** in the table are `code/tests/scripts/docs`: other files in `src/` (not counting `motion-not-yet.ts` and generated manifests), unit tests, scripts, and docs outside `docs/reports` and `docs/archive`. Shipped specs and plans count as docs, not as users.
- **Type errors:** no fresh count. Another `svelte-check` was running on this machine and `check:tsc` skips `.svelte` files, which is nearly all of these pages. The last recorded counts (Oct 14 swarm report `types-w4-testpages.md`) put 58 left in `ocean-character-lab` and 13 in `ocean-motion-benchmark`. The wave-5 reports list every other test page as fixed by inspection, not by a checker run. So every batch below shows **0 known**.
- **Not counted:** static assets, models and images the pages use under `static/`. Delete lists below are code only.
- **Each removal also needs** (a) the page folder removed, (b) its line removed from `src/lib/shared/transitions/motion-not-yet.ts` when listed there (the "waiting list only shrinks" test fails otherwise), and (c) a regenerate of `scripts/ceremony-manifest.json` is optional (generated). The rows below name the `motion-not-yet.ts` lines.

Ranked safest first. Each batch is one yes/no.
